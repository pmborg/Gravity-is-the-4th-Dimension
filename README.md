## 📌 Summary

- Extrinsic curvature \(K_{ij}\) is the **central dynamical quantity**.
- Matter on Σ determines \(K_{ij}\), which in turn determines intrinsic geometry via Gauss–Codazzi.
- Projecting 4D Einstein equations leads to a natural **effective 3D Einstein equation**.
- Cosmology emerges from the global embedding radius \(R(t)\).
- With \(\dot R = c\), the Hubble relation becomes:
  
  **H = c / R**

- Singularities are avoided: the 4D embedding remains smooth even where \(K_{ij}\) becomes large.
